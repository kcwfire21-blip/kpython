How to use KPython on iPhone

KPython runs Python right on your phone (Pyodide). Your code isn't uploaded anywhere.

1. Install

  • Open the KPython page in Safari.
  • Tap the Share button, then Add to Home Screen. It opens full screen like a normal app, with the KPython icon.
  • The first time you open it, it asks you to create a passcode (4+ characters). Tap Unlock. Tap 🔒 to lock it again.
  • The passcode only hides the screen. It does not encrypt anything.

Offline: after one load with internet, the app saves its own files plus Python, so it works without a signal. The badge in the header changes from ⏳ Caching… to ✈️ Offline ready when that's done. The first time Python downloads, a progress bar shows under the Python status and on the passcode screen. Packages you've loaded are saved for offline use too. When an update is ready, the app saves your editor and shows a bar to tap to reload. It never reloads by itself.

Lite start (off unless you turn it on): 📁 Files ▸ ⚙️ Settings ▸ Lite start waits to download Python (about 6 MB) until you first need it. The status then reads Python: starts on first Run; your first ▶ Run shows Starting Python… and runs as soon as it's ready.

2. Your first script

  • Go to the ⌨️ Code tab and wait until the button changes from "Loading Python…" to ▶ Run.
  • Tap ＋ for a new script, or 📚 to start from a snippet (see Snippet library below).
  • Type print("Hello, Keivon") and tap ▶ Run. The output shows up below.
  • input() works: the app asks you for the answer.
  • Stuck in a loop? Tap ⏹ Stop.
  • Your edits save automatically. 💾 saves now.
  • The >_ REPL tab is a Python console for quick one-line tests. Try help(str.split).
  • To add packages, type a name and tap Install, or tap numpy, pandas or matplotlib.

Find and replace: in the Code tab, tap 🔍 (Find/replace) to open the find bar. Type in Find. ▼ and ▲ jump to the next or previous match (Enter also goes to the next one), and the bar shows how many matches there are. Type in Replace with, then tap Replace to change the selected match or All to change every match. Tick Match case to match capital letters exactly. ✕ closes the bar. All doesn't ask first, so use the editor's undo (↶ on the keys row) if it changed too much.

Snippet library: 📚 jumps to 📚 Snippets on the Files tab. Pick a category in the list (or All). Each snippet has Open (copies it into a new script) and ▶ Run (copies it and runs it straight away). Team snippets show which bot made them. For bigger starter templates, use Dev ▸ 🧩 Templates.

3. Files

On the 📁 Files tab you'll see My Scripts, with these buttons:

  • ＋ New makes a new script.
  • 📥 Import .py brings in a script from the iPhone Files app.
  • Each script has Open, ⧉ (duplicate), ✎ (rename) and 🗑 (delete, which asks first; bring it back with ↶ Undo).
  • 📤 Export this file (in the Code tab) exports one script. It's not a backup.
  • 📂 Files in ~: tap ↻ Show to list the files your tools saved (GitHub imports, projects, CSVs, databases). Text files have Open as script (makes a copy as a saved script); ⬇️ saves any file to the phone.
  • ⚙️ Settings has the Lite start switch.

4. Dev tools

The 🛠 Dev tab works on the script that's open. Some useful ones:

  • 🧹 Lint checks the open script without running it, with two checkers. Eight's reports syntax errors, unused imports and variables, names that aren't defined, lines that are too long, and missing docstrings. bot2's quick lint adds shadowed builtins, mutable default arguments, bare except:, == None and unreachable code. Each finding has its line number. Fix them in the editor (🔍 helps you jump to a name), then tap Lint again. 🧹 Quick lint (menu) checks any file in ~ or pasted code.
  • 🔁 Find & replace in files searches files under ~ (plain text or regex, match case, whole words). For each file it shows a diff and asks y (write), N (skip), a (all remaining, which asks once more) or q (stop). It skips your saved scripts: change those with ✏️ Replace in saved scripts.
  • 📎 Snippet library keeps your own snippets with tags and {{name}} blanks to fill in. Insert asks the app to put it at the editor cursor: the app shows the whole text and inserts it only if you tap Insert.
  • ✨ Format tidies your code. 📝 Docstrings adds descriptions to your functions. Both show you the changes first and ask before applying them. Undo with ↶.
  • ✅ Run tests, ⏱ Profile, 🐞 Debug, 🧪 Coverage and 🧠 Memory run your code, so they ask first.
  • 🕘 Save version saves a copy of your script. 📜 History lets you compare versions or go back to an old one.
  • 🔑 Secret scan finds passwords or tokens left in your scripts.
  • 🧰 Tools ▸ 🛠 More has team scripts (Dev tools, Terminal, Job tracker, GitHub browser, Loan calc, Rent check). Tapping a button asks Open … as a new script and run it now? and then runs it in the Code tab.

Safety tip: in ⌨️ Terminal, python <file> and pip install ask you first (type y). Only run files you wrote or trust. Check package names carefully, or use Dev ▸ 📦 Packages, which confirms first.

5. GitHub push safety

Use 🧰 Tools ▸ 🐙 GitHub.

  • You can read public repos without logging in. Enter owner/repo and tap Open.
  • Logging in (for private repos and pushing): use a fine-grained token limited to just the repos you need, with only "Contents: Read and write" and a 30-day expiry. Never use a classic token.
  • The token stays in memory only. It's wiped when you lock the app, reload, or log out.
  • Python scripts can't read it.
  • ⬆ Push… shows the repo, path and branch. Nothing is pushed until you type yes. Double-check the branch first.
  • ▶ Run… on a downloaded file asks first. Only run code you trust.
  • The 🐙 GitHub browser in More is read-only. It can't run downloaded code. Save the file with s <number> and read it first.

6. Allowed sites

Your scripts can only reach the internet sites on this list, which includes the tester in Dev ▸ 🌐 HTTP. Open 🧰 Tools ▸ 🌐 Allowed sites.

  • Type an https:// address with no path, such as https://api.example.com, and tap Add. Then type yes to confirm. A raw IP address also asks you to type IP.
  • A running script can ask to add one site (once per run). You get a popup with the address and its reason, and nothing is added unless you tap OK. Python restarts after the run so the change applies. Scripts can't add sites on their own.
  • Reset to defaults… clears your additions after you type RESET.
  • The defaults include GitHub's API and PyPI.

7. Backups

Do this often. In 📁 Files ▸ Backup, tap ⬇️ Export to save one JSON file with every script, all your tool data and saved versions. Your passcode isn't included.

  • Save it to iCloud or Files.
  • ⬆️ Import restores a backup. It asks first, and scripts with the same name get replaced.
  • The backup covers your scripts, the Tools tab data, saved versions and the files in ~ (projects, SQLite databases, the task board's .tasks.json, the job tracker's job_apps.json, GitHub imports). It skips files over 2 MB and anything past 6 MB of files in total, and tells you which ones when you export. Your passcode and any GitHub token are never in it.
  • ↶ Undo brings back the last change made by Python, or a script you deleted.
  • Reset all data… wipes everything. Export a backup first!

Your scripts are stored as plain text on the phone, so don't paste passwords or tokens into scripts.

8. Troubleshooting

  • The button stays on "Loading Python…": connect to the internet once so Python can download, then reopen the app. With Lite start on, Python only starts when you tap ▶ Run.
  • "↻ Some background code from that run would not stop, so Python was restarted": a script left something running that ignored Stop. Console variables were cleared; just run again.
  • A script hangs: tap ⏹ Stop. If Python is busy, the Dev buttons tell you to tap Stop.
  • "⟳ KPython update ready. Tap to reload (your scripts are saved)." bar: tap it to reload. Your editor is saved first. You can also search the palette for Check for KPython update.
  • A fetch fails or gets blocked: add the site in 🌐 Allowed sites.
  • Something got deleted or changed: try ↶ Undo or 📜 History, or import your last backup.
  • A package won't install: only pure-Python or Pyodide-built packages work.

9. Finding things fast

  • Tap 📖 at the top to open this guide. The Jump to… menu next to ✕ Close guide goes straight to a section; both stay at the top while you scroll. Esc also closes it. Dev ▸ ❓ Help guide lets you search every tool by keyword.
  • Tap 🔎 (or Ctrl/⌘+K on a keyboard) to open the command palette: Search every tool and button… (lint, sites, merge). ↑↓ move, Enter opens, Esc closes. It understands words like "run all", "delete", "update".
  • 🧭 Getting-started tour (Dev tab) walks through the basics. It's offered once on first launch.
  • 🧪 Self-test all tools (Dev tab) checks every tool and remembers the last results.
  • 📘 Examples (Dev tab) has 10 small runnable examples.
  • Cancel (✕) on a question in a Dev tool goes back: to the previous menu in tools that have one, otherwise to the tool's start (it says ↩ Back to the start of the tool). Cancel twice in a row closes the tool.
  • The 🌓 menu at the top switches System, Light or Dark.
