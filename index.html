🔑 Log in (for private repos & push)
   
Use a fine-grained token limited to specific repos, with Contents: Read and write only and a 30-day expiry. Create one at github.com/settings/personal-access-tokens/new.
The token stays in memory only. It's never saved, and it's wiped when you lock the app, reload, or log out. Python scripts can't read it.
